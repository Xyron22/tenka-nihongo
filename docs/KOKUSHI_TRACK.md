## Learning sequence to implement

1. Warm up the topic's key Japanese terms/Kanji with kana and Indonesian meanings.
2. Explain one care concept in plain Indonesian with an original Japanese/kana example and a clearly bounded workplace scenario.
3. Practice reading the question's instruction, including 適切, 適切でない and 最も, so a negative instruction is not overlooked.
4. Answer original topic-aligned questions, normally with five options and one defensible best answer. Explain the correct answer and each distractor in Indonesian, including the concept/distinction being tested.
5. Review mistakes by topic, then build toward mixed/case-based sets with explicit source/edition dates and separate learning progress.

This sequence is TENKA's planned teaching design. It is not an assertion that either book uses that exact chapter order. Small learning sets are distinct from a timed official-length mock examination.
